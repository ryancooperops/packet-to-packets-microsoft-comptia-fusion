# Integration Labs

## Lab 1 — Security risk to Microsoft controls
Combine `src/security/risk_engine.py` with endpoint posture checks. Use the resulting priority
score to decide whether a device should be remediated, isolated, or escalated.

## Lab 2 — Network to collaboration
Use `src/network/segmentation.py` as a policy abstraction. Extend it with identity, application,
and conditional-access style attributes.

## Lab 3 — Data/AI quality gate
Use `src/data_ai/pipeline.py` before an AI workflow. Add PII detection, schema validation,
deduplication, and model-confidence thresholds.

## Lab 4 — Business application workflow
Use `src/dynamics/workflow.py` to model a service case lifecycle. Add SLA timers, ownership,
priority, and audit events.

## Lab 5 — End-to-end capstone
Build a simulated enterprise service:

1. Asset inventory
2. Network segmentation
3. Endpoint posture
4. Security finding prioritization
5. Data quality validation
6. Business-case workflow
7. Automated tests and CI
